The register map

The YM2413 answers to addresses 00–38. The eight user-instrument bytes are shared by every channel that selects instrument 0; the rest repeat once per channel.

The eight patch bytes, bit by bit

Registers 00–07 are one complete FM patch — the modulator on the even bytes, the carrier on the odd ones. This is the layout the ROM instruments use too.

Byte76543210Meaning

Pitch: note → (F-Number, Block)

The OPLL spells a pitch as a 9-bit F-Number and a 3-bit Block (octave): f = F · fSAM / 2^(19−Block), with fSAM = 3 579 545 / 72 ≈ 49 716 Hz. Type a note or a frequency; the encoder picks the smallest Block that keeps F-Number ≤ 511.

The Multiple table

Each operator's frequency is its pitch times a Multiple (the low nibble of byte 00/01). The 16 settings are not 0…15 — index 0 means ×½, and a few values repeat:

OPLL, OPL, and the VRC7

The YM2413 (OPLL) is the cut-down member of Yamaha's OPL family. The full OPL / OPL2 (YM3526 / YM3812) give every channel its own editable patch and more waveforms; the OPLL trades that away for a ROM of 15 fixed instruments + one user patch and a smaller die — which is exactly what made it cheap enough to put in the MSX's FM-PAC and built-in MSX-MUSIC. It is not MSX-AUDIO (the Y8950 / OPL), a different, richer chip.

The Konami VRC7 in some Famicom cartridges is an OPLL variant with a different instrument ROM and six channels. This site models the YM2413 only — the VRC7's sounds would need a second ROM and dilute the MSX focus.
