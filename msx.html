7 MSX

Everything you have changed on this site has been a register write. On a real MSX, the Z80 reaches the YM2413 through just two I/O ports: 7Ch (the address latch) and 7Dh (the data). To set a register you write the register number to 7Ch, then the value to 7Dh: two OUT instructions, with a short settle between them.

Those two ports are the whole hardware interface. The FM-PAC cartridge and the built-in MSX-MUSIC of MSX2+/turboR both expose it at the same ports; a small FM-BIOS in the cartridge ROM wraps these writes for BASIC, but the ports underneath are what every driver actually uses. The listing below is the exact sequence for whatever the chip is doing right now; change anything on any page and it rewrites itself.

Write-only: the shadow copy is not optional

You cannot read the YM2413 back. There is no port that returns a register's value — the chip only ever accepts writes. So any driver that wants to change one bit of a register without disturbing the others must keep its own copy in RAM of every byte it has written, modify that, and send the whole byte again. The register file at the bottom of every page on this site is that shadow copy — which is why editing a single bit there works at all.

What we do and don't model

This site models the chip: the operators, the envelopes, the ROM, rhythm, the register file. It does not emulate the Z80, the FM-BIOS, or the FM-PAC's SRAM, and it is not cycle-exact about the bus timing between the two OUTs. The full interactive code view — the exact OUT (7Ch)/(7Dh) sequence for the current state — and the decoded reference tables arrive with the next phase.
